La estructura for-else en Python es una característica poco común en otros lenguajes. Su regla es muy simple: 
el bloque else se ejecuta solo si el bucle for se completó por completo, es decir, si recorrió todos los elementos 
de la lista o rango sin ser interrumpido.

Si el bucle se interrumpe antes de tiempo usando la instrucción break, el bloque else se ignora por completo.


Estructura y Funcionamiento

A nivel de hardware, sirve para evitar usar variables "bandera" (booleanos como encontrado = True) para saber 
si un ciclo terminó con éxito o no.
- for elemento in lista:
-     if condicion:
-         # Si entramos aquí, el bucle se rompe y el ELSE NO SE EJECUTA
-         break
- else:
-     # Esto SOLO se ejecuta si el bucle terminó TODAS sus vueltas normalmente
-     print("El bucle terminó sin interrupciones")

Ejemplo Práctico: Buscar un virus en archivos

Imagina que estás escaneando una lista de archivos en tu computadora:
- archivos = ["foto.jpg", "documento.docx", "virus.exe", "musica.mp3"]
- 
- for archivo in archivos:
-     print(f"Analizando: {archivo}")
-     if archivo == "virus.exe":
-         print("¡ALERTA! Se encontró un virus. Abortando escaneo.")
-         break  # <--- Rompe el ciclo. El 'else' se anula.
- else:
-     # Este bloque solo corre si pasamos por todos los archivos sin activar el break
-     print("✓ Escaneo completado. Todo el sistema está limpio.")

• Resultado con la lista de arriba: Imprimirá el análisis hasta "virus.exe", dará la alerta y terminará. 
El mensaje del else no aparecerá.
• Resultado si quitas "virus.exe" de la lista: El for revisará los 3 archivos restantes con éxito y, al no 
haber más elementos, la CPU saltará directo a ejecutar el bloque else, imprimiendo: "✓ Escaneo completado. 
Todo el sistema está limpio."
