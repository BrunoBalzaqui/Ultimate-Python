Para que el código de Python de alto nivel que escribes en VS Code se convierta en acciones que el procesador 
de tu computadora entienda, pasa por un proceso de traducción y ejecución paso a paso.
A diferencia de lenguajes como C o C++ que se compilan directamente a lenguaje de máquina antes de ejecutarse, 
Python es un lenguaje principalmente interpretado que utiliza un proceso híbrido (compilación interna + interpretación).


El viaje del código: de Alto Nivel a Lenguaje de Máquina

El proceso exacto que ocurre tras bambalinas cuando presionas "Play" se divide en estas etapas principales:

1. El Código de Alto Nivel (Tu archivo .py)

Escribes código con sintaxis humana (como print("Hola")). La computadora no entiende esto directamente porque 
los procesadores solo procesan impulsos eléctricos (bits: ceros y unos).

2. Compilación interna a Bytecode (El compilador de Python)

Antes de ejecutar nada, el intérprete de Python (usualmente CPython, la implementación estándar) activa un compilador interno.
• ¿Qué hace? Traduce tu texto de alto nivel a un lenguaje intermedio de bajo nivel llamado Bytecode (archivos con extensión .pyc 
que a veces ves en una carpeta llamada __pycache__).
• ¿Por qué? El bytecode es un set de instrucciones simplificado, optimizado y compacto, diseñado para ser procesado de forma 
ultra rápida. Es independiente del sistema operativo.

3. La Máquina Virtual de Python (PVM)

El bytecode no corre directamente en el procesador físico de tu computadora (Intel, AMD, M1/M2). En su lugar, se envía a la 
Python Virtual Machine (PVM) o Máquina Virtual de Python.
• La PVM es un software que actúa como un procesador emulado o "falso".
• Contiene el Intérprete real de Python, el cual lee el bytecode línea por línea (instrucción por instrucción) en tiempo de ejecución.

4. Traducción a Lenguaje de Máquina (El Set de Instrucciones)

La PVM toma cada instrucción del bytecode y la traduce inmediatamente a instrucciones binarias nativas (código de máquina) específicas 
para tu sistema operativo y la arquitectura de tu procesador (por ejemplo, el set de reglas x86-64 o ARM).

5. Ejecución en el Procesador (Hardware)

Finalmente, la Unidad Central de Procesamiento (CPU) recibe estas ráfagas de ceros y unos a nivel físico, ejecuta los cálculos lógicos 
y VS Code captura esa salida para mostrártela en la pantalla de la terminal.

Resumen del Flujo de Ejecución

text
[ Código de Alto Nivel ] (.py)
         │
         ▼  (Compilador interno de Python)
[      Bytecode        ] (.pyc)
         │
         ▼  (Máquina Virtual de Python - PVM)
[ Lenguaje de Máquina  ] (Ceros y unos específicos de tu CPU)
         │
         ▼
[ Ejecución en Hardware ] (Resultado en tu pantalla)
Use code with caution.

Conceptos clave que mencionaste:

• Lenguaje de alto nivel: Sintaxis abstracta y comprensible para humanos (Python).
• Compilador vs. Intérprete: Python usa ambos. Primero compila a bytecode de forma invisible y luego interpreta ese bytecode línea por línea.
• Set de reglas (Instrucciones): El puente final. Cada procesador tiene su propio diccionario de comandos de hardware; la máquina virtual 
se encarga de que el bytecode genérico se adapte perfectamente a las reglas de tu chip específico.
